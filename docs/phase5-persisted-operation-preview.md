Status: BLOCKED until the paired backend is deployed and remaining accounting/event authority acceptance criteria close.

## Findings and changes

SLB previously previewed a browser contract snapshot and saved through generic contract persistence. Sublease saved before computing its effect. Current v2 forms now send only proposed fields, company, reporting date and contract ID to the persisted-operation endpoint. Save requires the server receipt and FORM_ONLY authority. Preview failure, form/contract/company/period changes and navigation invalidate acceptance; duplicate clicks are guarded. Only a successful server save updates the local display cache. Form save is explicitly distinguished from an accounting event or ledger posting. The backend must be deployed first.

The current right-side design is the only user workflow exercised in the authenticated browser suite. Tests now use its visible sidebar, contract rows/tabs, journal export menu and report-package disclosure inside v2. Frozen February clocks select the same January period as the isolated authority fixtures. Raw DTO and export comparisons remain unchanged. An outage leaves the current v2 disclosure export disabled.
